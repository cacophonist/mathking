# Brick Stack King (Math King)

An interactive counting and brick stacking game designed for kids.

Play live at: **[https://cacophonist.github.io/mathking/](https://cacophonist.github.io/mathking/)**

## Overview
- Single-page web application built with HTML5 Canvas, modern CSS, and vanilla JavaScript.
- Animated little builder character that runs, hops, carries bricks, and crowns himself upon reaching 10 bricks.
- Responsive design tailored for desktops, tablets, and mobile devices.
